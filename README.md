## Отчет об использовании ИИ

**Используемый инструмент:** DeepSeek (в роли ассистента).

**Мой промпт:** 
"Разработай приложение на HTML/JS/CSS с Bootstrap 5 для тестирования по C#. Сделай красивый дизайн. Данные (вопросы) должны загружаться из Google Таблицы по ссылке [ссылка]. Учти, что таблица в формате CSV."

**Что ИИ сделал правильно:**
Нейросеть отлично справилась с версткой (CSS, градиенты, карточки), написала рабочий парсер CSV-файлов и логику переключения вопросов. Код был практически готов к использованию.

**Что пришлось исправлять (и почему):**
1. *Ссылка на таблицу.* ИИ выдал код, который ожидал прямую ссылку на CSV, но я дал ему ссылку формата `pubhtml`. Пришлось добавить замену `.replace('/pubhtml', '/pub?output=csv')`, так как Google не отдает чистый CSV с первой ссылки.
2. *Обработка ошибок (CORS и доступ).* ИИ не предусмотрел проверку на то, что вернул сервер. Если таблица закрыта, Google возвращает HTML-страницу логина. Я добавил проверку `if (csvText.includes("<!DOCTYPE html>"))`, чтобы код не "ломался".
3. *Отсутствие try/catch.* В первоначальном варианте не было блока `try...catch` вокруг `fetch`, из-за чего при потере интернета страница просто зависала. Я добавил его и вывод `alert` для пользователя.

**Чему я научился:**
Я понял, как работает метод `fetch` для получения данных из внешних источников (Google Sheets). Научился обрабатывать ошибки сети и неверные данные. Также я разобрался, как публиковать статические сайты через GitHub Pages и как правильно оформлять Pull Request.
